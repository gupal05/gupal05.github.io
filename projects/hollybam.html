프로젝트 개요

Hollybam은 성인 인증을 기반으로 한 프리미엄 쇼핑몰 플랫폼입니다. 인증되지 않은 사용자는 인트로 페이지만 접근할 수 있도록 설계된 고보안 구조를 가지고 있으며, 상품 관리, 결제, 주문, 리뷰, 관리자 페이지 등 전자상거래의 모든 요소를 직접 설계하고 구현했습니다. 또한 AWS 기반의 클라우드 인프라를 구축하여 실제 상용 서비스로 운영 중입니다.

⚙️ 기술 설계 및 구현

1️⃣ Spring Boot + MyBatis 기반 백엔드 구조

ORM의 자동화보다 명확한 SQL 제어가 필요하다고 판단하여 MyBatis를 선택했습니다.
Service-DAO 구조를 통해 트랜잭션 단위를 세분화하였고, 대량 데이터 처리 시 성능을 위해 batch insert/update 기능을 사용했습니다.

2️⃣ JWT 기반 인증 및 본인인증 연동

자체 회원 로그인은 JWT 토큰 인증으로 구현하고, 비회원 접근 제한을 위해 NICE 본인인증 API를 연동했습니다.
인증이 완료되지 않은 사용자는 Spring Security의 OncePerRequestFilter로 모든 페이지 접근이 차단됩니다.

3️⃣ 결제 및 주문 처리

PG사 API를 이용한 카드 결제 및 포인트 결제를 구현했습니다.
결제 승인 후 데이터 정합성을 위해 트랜잭션 + 로그 테이블 이중 구조를 적용하여 장애 복구 시에도 주문 내역이 유지되도록 설계했습니다.

4️⃣ AWS 기반 인프라

EC2(Nginx + Spring Boot + Certbot), RDS(MySQL), S3(이미지 저장소)로 구성했습니다.
Docker Compose로 서비스 컨테이너를 관리하고, GitHub Actions를 통해 main 브랜치 push 시 자동 배포(CI/CD)가 이루어집니다.

5️⃣ SEO 및 접근성

인트로 페이지만 색인 대상으로 설정하고 Open Graph, Twitter Card 메타 태그를 적용하여 검색 노출 품질을 향상시켰습니다.
Lighthouse 기준 접근성/SEO 점수 90점 이상을 유지합니다.
