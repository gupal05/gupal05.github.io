프로젝트 개요

👥 프로젝트 인원: 1명 (개인 단독 개발)

📅 개발 기간: 2025년 6월 ~ 2025년 8월

🧑‍💻 담당 역할: 백엔드 및 프론트엔드(Thymeleaf) 전체 개발, 서버 인프라 구축 및 운영

Hollybam은 (주)혜안파트너스의 실제 사업으로 진행된 상용 서비스입니다.
성인 인증을 기반으로 한 프리미엄 쇼핑몰로, 인증되지 않은 사용자는 인트로 페이지만 접근할 수 있으며 회원/비회원 주문, 장바구니, 리뷰, 결제 등 전자상거래 기능 전반을 구현했습니다.

서비스의 백엔드, 프론트엔드(Thymeleaf), 배포 및 인프라 운영을 모두 직접 수행하였으며 현재 실제 고객이 이용 중인 상용 서비스로 안정적으로 운영되고 있습니다.

⚙️ 기술 설계 및 구현

1️⃣ MVC 구조 기반 백엔드 설계

Spring Boot MVC 패턴으로 Controller, Service, DAO를 명확히 분리하여 유지보수성과 확장성을 높였습니다. SQL은 Mapper XML로 관리하고, 비즈니스 로직은 Service 단에서 처리하여 구조적 안정성을 확보했습니다.

2️⃣ 세션 기반 인증 및 성인인증 보안 강화

Spring Security 기반으로 세션 인증을 구현하고, 비밀번호는 BCrypt로 암호화했습니다. NICE 본인인증 API를 연동하여 성인 여부를 검증하며, 인증되지 않은 사용자는 서비스 접근이 차단됩니다.

3️⃣ 결제 시스템 구축

PG사(레드커머스) API를 연동하여 카드 결제 및 간편 결제를 지원했습니다. 결제 상태와 오류는 payment_log 테이블에 저장되어 장애 대응이 용이합니다.

4️⃣ 배포 및 인프라

AWS EC2 환경에서 Docker Compose로 Nginx, Certbot, Spring Boot 컨테이너를 관리했습니다. GitHub Actions를 통해 main 브랜치 병합 시 자동 배포되도록 CI/CD 파이프라인을 구성했습니다.

5️⃣ SEO 및 접근성 최적화

인트로 페이지만 색인 대상으로 지정하고 meta/OG 태그를 구성해 Google Search Console 및 SNS 공유 시 미리보기 최적화를 완료했습니다.

6️⃣ 접근 제어 및 정책 구조

성인인증 및 세션 상태를 기반으로 Spring Security 필터 체인을 구성하여 인증되지 않은 사용자는 주요 서비스 페이지 접근이 제한되도록 설계했습니다.

🗄 데이터베이스 구조

Hollybam 서비스는 제품, 회원, 주문, 결제, 리뷰 등 다양한 도메인으로 구성되어 있으며 실제 운영 단계에서는 30개 이상의 테이블이 존재합니다.

아래 ERD는 핵심 도메인 중심으로 정리된 구조로, 민감 정보 및 내부용 보조 테이블을 제외한 주요 테이블만 발췌하였습니다.

각 테이블은 명확한 FK 제약 조건을 통해 데이터 무결성을 유지하고 있으며, 확장성(상품 옵션, 쿠폰, 포인트, 리뷰 이미지 등)을 고려해 유연하게 설계했습니다.

※ ERD는 운영 환경에서 사용 중인 전체 구조 중 일부를 시각화한 버전입니다.

💡 프로젝트 회고

Hollybam은 (주)혜안파트너스의 상용 서비스 프로젝트로, 기획 단계부터 서버 구축, 배포, 운영까지 전 과정을 단독으로 수행했습니다.

성인인증 기반 접근 제어, 결제 로직, 트랜잭션 처리 등 실제 상업 서비스 운영에 필요한 모든 기능을 직접 개발하며 백엔드 개발자로서의 실질적 기술력을 다졌습니다.

또한 운영 중 발생한 인증 API 지연, SSL 인증서 갱신, 배포 자동화 오류 등을 직접 해결하며 실제 운영 환경에서의 장애 대응 및 서비스 안정화 경험을 쌓았습니다.
