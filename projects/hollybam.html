프로젝트 개요

Hollybam은 성인 인증 기반의 프리미엄 쇼핑몰로, 인증되지 않은 사용자는 인트로 페이지만 접근할 수 있도록 설계된 고보안 전자상거래 플랫폼입니다. 상품, 주문, 결제, 리뷰, 관리자 페이지 등 운영에 필요한 모든 기능을 구현하고 AWS를 통해 실서비스 중입니다.

📸 화면 미리보기

인트로 페이지 — 브랜드 소개 및 성인 인증 진입점
본인인증 단계 1 — 이름/생년월일 입력
본인인증 단계 2 — 휴대폰 인증 완료
메인 페이지 — 상품 리스트 및 프로모션 배너
주문서 작성 1 — 주문자 정보 및 배송지 입력
주문서 작성 2 — 결제 수단 선택 및 포인트 사용
결제 페이지 — PG 결제창 호출
결제 완료 — 결제 승인 후 영수증 출력
관리자 대시보드 — 회원/주문/매출 현황 시각화
ERD — 상품, 주문, 리뷰 등 주요 테이블 구조

💡 회고 및 기술 스택

이 프로젝트를 통해 실제 운영 가능한 쇼핑몰의 전 과정을 설계하고, EC2 + Docker 기반 배포와 RDS 스키마 설계를 실무 수준으로 구현했습니다.
CI/CD 자동화를 통해 지속적인 배포 환경을 구축했으며, 추후 Redis 캐싱을 도입하여 속도 향상을 계획 중입니다.
