프로젝트 개요

Hollybam은 (주)혜안파트너스의 사업으로 진행된 실제 상용 서비스입니다.
성인 인증을 기반으로 한 프리미엄 쇼핑몰로, 인증되지 않은 사용자는 인트로 페이지만 접근 가능하며 회원/비회원 주문, 장바구니, 리뷰, 결제 등 전자상거래 기능 전반을 구현했습니다.
서비스의 모든 백엔드 설계, 배포, 운영을 단독으로 수행하였으며, 현재 실제 고객이 이용 중입니다.

⚙️ 기술 설계 및 구현

1️⃣ MVC 구조 기반 백엔드 설계

Spring Boot MVC 패턴으로 Controller, Service, DAO를 분리하여 유지보수성을 높였습니다. SQL은 Mapper XML로 관리하며, Service 단에서 비즈니스 로직을 처리하도록 구조화했습니다.

2️⃣ 세션 기반 인증 및 보안 강화

Spring Security 기반으로 세션 인증을 구현하고 비밀번호는 BCrypt로 암호화했습니다. NICE 본인인증 API를 통해 성인 인증을 진행하며, 인증되지 않은 사용자는 서비스 접근이 제한됩니다.

3️⃣ 결제 시스템 구축

PG사(레드커머스) API를 연동하여 카드 결제 및 간편 결제를 지원했습니다. 결제 과정의 상태와 오류는 payment_log 테이블에 저장되어 장애 대응이 용이합니다.

4️⃣ 배포 및 인프라

AWS EC2 환경에서 Docker Compose로 Nginx, Certbot, Spring Boot 컨테이너를 관리했습니다. GitHub Actions로 main 브랜치 병합 시 자동 배포되도록 CI/CD 파이프라인을 구성했습니다.

5️⃣ SEO 및 접근성

인트로 페이지만 색인 대상으로 지정하고 meta/OG 태그를 구성해 Google Search Console 및 SNS 공유 시 미리보기 최적화를 완료했습니다.

💡 프로젝트 회고

Hollybam은 (주)혜안파트너스에서 진행된 실제 상용 서비스 프로젝트입니다.
