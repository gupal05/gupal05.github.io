프로젝트 개요

Hollybam은 성인 인증을 기반으로 한 프리미엄 쇼핑몰 플랫폼으로, 인증되지 않은 사용자는 인트로 페이지 외에는 접근이 불가능하도록 설계되었습니다.

PG 결제, 본인인증, 소셜 로그인, 리뷰 작성, 관리자 페이지 등 쇼핑몰 운영 전반의 기능을 통합적으로 구현했습니다. AWS EC2, RDS, S3를 이용하여 안정적으로 서비스가 운영 중입니다.

주요 기능

🔐 본인 인증 및 접근 제한

NICE 인증 API를 연동하여 인증된 사용자만 사이트 접근이 가능하도록 구현했습니다.

🛒 상품 및 주문 시스템

상품, 옵션, 할인, 쿠폰, 재고, 주문 이력을 관리할 수 있는 구조로 설계했습니다.

💳 결제 처리

레드커머스 PG 모듈을 통한 카드 및 간편결제를 지원하며 결제 로그를 RDS에 기록합니다.

📷 포토리뷰 관리

리뷰 이미지를 AWS S3에 저장하고, 비회원 리뷰 작성도 가능하도록 처리했습니다.

📊 관리자 대시보드

회원 수, 주문 건수, 인기 상품, 일별 매출을 한눈에 확인할 수 있도록 시각화했습니다.

기술 구현 및 아키텍처

Spring Boot + MyBatis로 서버를 구축하고, Docker를 통한 컨테이너 환경에서 EC2 배포를 수행했습니다.

GitHub Actions로 CI/CD 파이프라인을 구성하여 main 브랜치 머지 시 자동 빌드 및 배포가 이루어집니다.

ERD 설계를 통해 테이블 관계를 명확히 정의하여 데이터 무결성과 조회 성능을 최적화했습니다.

회고 및 개선

본 프로젝트를 통해 EC2 + Docker 기반 배포 파이프라인과 실무 수준의 데이터베이스 모델링 경험을 쌓았습니다. 추후 Redis 캐싱 및 ElasticSearch 도입으로 검색 성능을 개선할 계획입니다.
