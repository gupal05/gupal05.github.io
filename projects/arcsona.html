프로젝트 개요

👥 프로젝트 인원: 백엔드 2명 · 프론트엔드 2명

📅 개발 기간: 2025년 9월 ~ 진행 중

Arcsona는 이어폰·헤드셋 등 프리미엄 음향기기를 판매하는 온라인 플랫폼으로, 프론트엔드는 Next.js, 백엔드는 Spring Boot로 분리되어 개발되었습니다.

백엔드에서는 PostgreSQL 기반의 ERD 설계, JWT 인증, Redis 캐시, Flyway 버전관리 등 확장성과 협업 중심의 구조로 설계되었습니다. 현재는 AWS 배포 및 CI/CD 자동화 단계를 진행 중입니다.

⚙️ 기술 설계 및 구현

1️⃣ JPA + Flyway 기반 DB 관리

PostgreSQL을 기반으로 ERD를 설계하고, Flyway를 통해 버전별 마이그레이션을 자동 관리했습니다.

2️⃣ JWT 기반 인증 구조

Spring Security와 JWT를 활용해 Admin / Member / Public 권한 체계를 구축했습니다. Swagger에서 권한별 API 호출 테스트가 가능하도록 구성했습니다.

3️⃣ Docker 환경 구성

Redis, DB, 백엔드 서버를 Docker Compose로 통합 실행하여 환경 차이를 제거했습니다.

4️⃣ API 문서 자동화

Swagger 3.0을 적용하여 실시간 API 문서를 자동 생성하고 팀 간 협업 효율을 높였습니다.

🗄 데이터베이스 구조 (ERD)

Arcsona는 상품, 옵션, 주문, 결제, 리뷰, 회원, 쿠폰 등 약 30개 이상의 테이블로 구성되어 있습니다.
정규화를 통해 데이터 중복을 최소화하고, FK 기반 참조 무결성을 유지했습니다.

📡 API 테스트 및 문서

Postman을 활용한 JWT 로그인 테스트와 Swagger 기반 API 명세서를 통해 협업 효율을 높였습니다.

Postman — JWT 로그인 요청
Swagger — 관리자 API 목록
Swagger — 회원 전용 API 목록
Swagger — 공개 API 목록

💡 프로젝트 회고

Arcsona는 팀 단위 협업을 통해 실무 수준의 백엔드 구조를 설계한 프로젝트입니다.
ERD 정규화, Flyway 버전관리, Swagger 협업 환경 등 실무형 개발 문화를 체득했으며, 특히 JWT 기반 인증·인가 구조와 Redis 세션 관리를 통해 성능과 보안성을 향상시켰습니다.

현재는 AWS 배포 및 CI/CD 자동화 구축을 진행 중이며, 실 서비스 운영을 목표로 안정화 단계를 밟고 있습니다.
