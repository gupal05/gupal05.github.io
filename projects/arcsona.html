Arcsona 프로젝트

🚧 현재 배포 준비 중 (미공개)
Spring Boot JPA PostgreSQL Redis Flyway Docker JWT Swagger 3.0 CI/CD

프로젝트 개요

👥 프로젝트 인원: 백엔드 2명 · 프론트엔드 2명

📅 개발 기간: 2025년 9월 ~ 진행 중

Arcsona는 이어폰·헤드셋 등 프리미엄 음향기기를 판매하는 온라인 플랫폼으로, 프론트엔드는 Next.js, 백엔드는 Spring Boot로 분리된 구조로 개발되었습니다.

백엔드에서는 PostgreSQL 기반의 ERD 설계, JWT 인증, Redis 캐시, Flyway 버전관리 등 확장성과 협업 중심의 구조로 설계되었습니다. 현재는 AWS 배포 및 CI/CD 자동화 단계를 진행 중입니다.

🗄 데이터베이스 구조 (ERD)

ERD — PostgreSQL 기반 DB 구조 (30개 이상 테이블)

📡 API 테스트 및 문서

JWT 인증과 권한별 API를 Postman과 Swagger를 통해 검증하고 문서화했습니다.

Postman — JWT 로그인 테스트
Swagger(Admin) — 관리자 API 목록 (1)
Swagger(Admin) — 관리자 API 목록 (2)
Swagger(Admin) — 관리자 API 목록 (3)
Swagger(Member) — 회원 API (1)
Swagger(Member) — 회원 API (2)
Swagger(Member) — 회원 API (3)
Swagger(Member) — 회원 API (4)
Swagger(Public) — 공개 API (1)
Swagger(Public) — 공개 API (2)

💡 프로젝트 회고

Arcsona는 팀 단위 협업을 통해 실무 수준의 백엔드 구조를 설계한 프로젝트입니다.
ERD 정규화, Flyway 버전관리, Swagger 협업 환경 등 실무형 개발 문화를 체득했으며, 특히 JWT 기반 인증·인가 구조와 Redis 세션 관리를 통해 성능과 보안성을 향상시켰습니다.

현재는 AWS 배포 및 CI/CD 자동화 구축을 진행 중이며, 실 서비스 운영을 목표로 안정화 단계를 밟고 있습니다.
