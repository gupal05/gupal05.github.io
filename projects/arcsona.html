프로젝트 개요

👥 프로젝트 인원: 총 4명 (프론트엔드 2명 · 백엔드 2명)

📅 개발 기간: 2025년 8월 ~ 2025년 9월

🧑‍💻 담당 역할: 백엔드 개발 (도메인 설계, CRUD API 구현, Flyway 설정, Redis 캐시, Swagger 문서화)

Arcsona는 프리미엄 이어폰·헤드셋을 판매하는 온라인 쇼핑몰로, 사용자의 주문 흐름과 상품 관리 기능을 안정적으로 처리하기 위한 도메인 기반 구조로 설계되었습니다.

모든 데이터는 PostgreSQL 기반으로 정규화되어 있으며, JPA 연관관계 매핑을 통해 상품-옵션-이미지 구조를 유연하게 관리하도록 구현했습니다.

⚙️ 기술 설계 및 구현

1️⃣ 도메인 중심의 CRUD 설계

상품, 옵션, 이미지, 회원, 주문 등 주요 기능을 각 도메인 단위로 분리하고 Entity-DTO 매핑과 Service-Repository 구조를 명확히 구분하여 유지보수성을 높였습니다.

2️⃣ 데이터 정규화 및 성능 최적화

테이블 간 관계를 정규화하여 데이터 중복을 제거하고, 필요 시 Lazy Fetch 전략을 통해 불필요한 조회를 최소화했습니다.

3️⃣ Flyway 기반 DB 마이그레이션

버전별 SQL 마이그레이션을 자동화하여 모든 개발 환경에서 동일한 DB 구조를 유지했습니다. DB 변경 시 수동 적용 없이 자동 반영되도록 설정했습니다.

4️⃣ Redis 기반 주문 임시 저장

사용자가 주문 과정을 진행할 때, 결제 완료 전 단계의 주문 정보를 Redis에 임시로 저장해 안정적인 주문 흐름을 유지했습니다. 이를 통해 서버 재시작 시에도 데이터 손실 없이 프로세스를 복원할 수 있습니다.

5️⃣ Swagger 기반 API 문서화

Swagger 3.0을 적용해 프론트엔드 팀과의 협업 효율성을 높였으며, 인증·비인증 API를 구분해 관리할 수 있도록 구성했습니다.

💡 프로젝트 회고

Arcsona는 팀 단위 협업을 통해 실제 상용 수준의 쇼핑몰 아키텍처를 설계한 프로젝트입니다.

주문·상품 관리 등 CRUD 기반의 핵심 기능을 구현하며, 도메인 모델링, DB 정규화, Redis 캐시, Flyway 마이그레이션의 중요성을 깊이 이해했습니다.

특히 주문 단계에서 Redis를 활용한 임시 저장 구조를 구현하며 결제 안정성과 사용자 경험을 동시에 개선할 수 있었습니다.

현재는 AWS 배포를 위한 인프라 준비 단계로, 향후 상용화를 목표로 확장 중입니다.
