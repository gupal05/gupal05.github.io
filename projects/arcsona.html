💡 프로젝트 개요

Arcsona는 고급 오디오 기기를 판매하는 이커머스 플랫폼으로, 실무 환경에서의 협업을 염두에 두고 백엔드 아키텍처를 직접 설계 및 구현한 프로젝트입니다.

해당 프로젝트는 단일 모놀리식 구조로 구축되었으며, 인증·인가 처리, DB 마이그레이션 자동화, 캐시 처리, API 문서화 등 실제 운영 환경에서 요구되는 핵심 기능을 직접 구현했습니다.

백엔드 파트에서는 Spring Security 기반의 JWT 인증 시스템, Redis 캐싱 구조 설계, Flyway DB 버전 관리, Docker Compose 통합 환경 등을 주도적으로 담당했습니다.

🧩 주요 구현 기능

  • JWT + Spring Security 기반 인증 및 인가 처리
  • Redis를 활용한 세션 및 캐시 관리
  • Flyway를 통한 DB 마이그레이션 자동화
  • Swagger로 API 명세 및 테스트 환경 구축
  • Postman을 통한 JWT 토큰 발급 및 인증 테스트
  • Docker Compose로 로컬 통합 개발 환경 구성
  • 협업형 브랜치 전략 (feature/develop/main 구조 적용)

🧾 API 테스트 및 문서화

Arcsona의 모든 API는 JWT 기반 인증 구조를 따르며, Postman에서 로그인 후 토큰을 발급받아 Swagger Authorization에 적용하여 테스트했습니다.

🗂️ 데이터베이스 ERD

프로젝트에서 사용된 ERD는 핵심 12개 테이블 중심으로 구성되어 있으며, UUID 기반 PK를 통해 식별성을 유지합니다.
실제 운영 환경에서는 주문, 결제, 쿠폰, 로그 테이블 등을 포함한 총 30개 이상의 테이블이 존재합니다.

📘 프로젝트 회고

Arcsona는 단순한 기능 구현을 넘어, 실무 협업형 백엔드 개발 프로세스를 경험하기 위한 프로젝트였습니다.

• JWT 인증 로직과 Spring Security 필터 체인 커스터마이징
• Redis 캐시 구조 최적화 및 TTL 정책 설계
• Flyway 스크립트 기반 DB 관리 자동화
• Swagger / Postman으로 API 테스트 자동화
• Docker Compose로 로컬·팀원 간 환경 통일

이를 통해 실제 기업 환경에서 발생할 수 있는 인프라 및 데이터 관리 이슈를 경험적으로 해결할 수 있었고, 팀 단위 협업 속에서도 주도적으로 백엔드 아키텍처를 설계·운영하는 역량을 키웠습니다.
