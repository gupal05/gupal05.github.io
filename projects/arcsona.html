프로젝트 개요

👥 프로젝트 인원: 백엔드 2명 · 프론트엔드 2명

📅 개발 기간: 2025년 9월 ~ 진행 중

Arcsona는 이어폰·헤드셋 등 프리미엄 음향기기를 판매하는 온라인 플랫폼으로, 프론트엔드는 Next.js, 백엔드는 Spring Boot로 분리된 구조로 개발되었습니다.

백엔드에서는 PostgreSQL 기반의 ERD 설계, JWT 인증, Redis 캐시, Flyway 버전관리 등 확장성과 협업 중심의 구조로 설계되었습니다. 현재는 AWS 배포 및 CI/CD 자동화 단계를 진행 중입니다.

🧩 시스템 아키텍처

Client (Next.js)
⬇
Nginx (API Gateway)
⬇
Spring Boot Backend
⬇
Flyway (DB Migration / Schema Sync)
⬇
PostgreSQL (RDS)
➡

Flyway는 애플리케이션 실행 시 DB 스키마를 자동 마이그레이션하여 모든 개발자의 로컬 및 서버 환경에서 동일한 구조를 유지합니다.
Docker Compose 기반 통합 실행 · CI/CD 자동화 · AWS 배포 준비 중

🗄 데이터베이스 구조

Arcsona 서비스는 회원, 상품, 주문, 리뷰 등 다양한 도메인으로 구성되어 있으며, 실제 운영 단계에서는 30개 이상의 테이블이 존재합니다.
아래 ERD는 핵심 도메인 중심으로 정리된 구조로, 민감 정보와 내부용 보조 테이블을 제외한 주요 테이블만 발췌하였습니다.

※ ERD는 운영 환경에서 사용 중인 전체 구조 중 일부를 시각화한 버전입니다.

💡 프로젝트 회고

Arcsona는 팀 단위 협업을 통해 실무 수준의 백엔드 구조를 설계한 프로젝트입니다.
ERD 정규화, Flyway 버전관리, Swagger 협업 환경 등 실무형 개발 문화를 체득했으며, 특히 JWT 기반 인증·인가 구조와 Redis 세션 관리를 통해 성능과 보안성을 향상시켰습니다.

현재는 AWS 배포 및 CI/CD 자동화 구축을 진행 중이며, 실 서비스 운영을 목표로 안정화 단계를 밟고 있습니다.
