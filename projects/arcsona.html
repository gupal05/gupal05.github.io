🧩 Arcsona Project (E-Commerce Platform)

Spring Boot 3.3 · JPA · PostgreSQL · Redis · Flyway · Docker · JWT · Swagger 3.0

👥 프로젝트 인원: 백엔드 2명 · 프론트엔드 2명

📅 개발 기간: 2025년 9월 ~ 진행 중

프로젝트 개요

Arcsona는 프리미엄 이어폰·헤드셋 중심의 온라인 판매 플랫폼으로, 프론트엔드(Next.js)와 백엔드(Spring Boot)가 분리된 구조로 개발되었습니다.

현재는 배포 준비 단계로, AWS EC2·RDS·S3 기반 환경 구성과 CI/CD 자동화를 진행 중입니다. 백엔드 전반의 설계, 인증 구조, DB 모델링, API 개발을 담당했습니다.

  • PostgreSQL 기반 ERD 설계 및 Flyway로 버전 관리
  • Spring Security + JWT 기반 권한별 인증 구조 구축 (Admin / Member / Public)
  • Swagger를 통한 실시간 API 문서 자동화 및 협업 지원
  • Docker Compose로 환경 일원화 및 배포 자동화 설계
  • Redis를 활용한 인증 캐싱 및 세션 관리 최적화
