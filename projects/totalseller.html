프로젝트 목적

TotalSeller Backoffice는 기업 내 판매 및 계약 프로세스를 관리하기 위한 사내 관리 시스템입니다. 보고서, 프로세스, 고객 관리, 직원 계정 승인 등 주요 업무를 중앙에서 효율적으로 관리할 수 있도록 개발되었습니다.

시스템 아키텍처

Spring Boot 애플리케이션은 Docker 환경에서 구동되며, GitHub Actions를 통해 EC2에 자동 배포됩니다. 데이터베이스 마이그레이션은 Flyway를 통해 팀 전체의 스키마 일관성을 유지하며, PostgreSQL RDS를 사용하여 안정성과 성능을 확보했습니다.

회고

백엔드 전반을 담당하며 DB 모델링, ERD 설계, API 명세서 작성 및 Flyway 기반 마이그레이션 환경을 구축했습니다. CI/CD는 GitHub Actions를 사용하여 Docker 기반으로 자동 배포되도록 구성하였고, 내부 보안 정책에 따라 로그인 인증이 필수인 구조로 설계했습니다. 현재는 코드 구조를 리팩토링하며 유지보수성을 향상시키는 작업을 진행 중입니다.
