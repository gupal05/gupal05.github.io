프로젝트 개요

👥 프로젝트 인원: 백엔드 2명 · 프론트엔드 1명

📅 개발 기간: 2025년 10월 13일 ~ 10월 30일 (리팩토링 진행 중)

TotalSeller Backoffice는 사내 직원용 관리 시스템으로, 고객·파트너·계약·보고서·프로세스 등 판매 및 운영 데이터를 통합 관리하는 내부 전용 플랫폼입니다.

모든 API는 인증이 필요한 구조로 보호되며, 로그인하지 않으면 어떤 서비스도 접근할 수 없습니다. 프로젝트의 백엔드 구조 설계, 데이터 모델링, Flyway 기반 DB 버전 관리, CI/CD 자동 배포 환경 구축을 담당했습니다.

🗄 데이터베이스 구조

주요 테이블은 팀, 직원, 클라이언트, 파트너, 오퍼링, 프로세스, 보고서 등으로 구성되며 Flyway를 통해 모든 개발자의 DB 스키마 버전을 일관되게 관리했습니다.

※ 보안상 민감 데이터는 제외하고, 주요 도메인 중심으로 정리한 ERD입니다.

📡 Swagger API 문서

Swagger 3.0을 통해 API 명세를 자동화하고, 팀 내 협업 및 테스트 효율성을 극대화했습니다.
각 API는 역할별로 구분되어 있으며, JWT 인증 기반으로 접근이 제어됩니다.

💡 프로젝트 회고

이번 프로젝트에서는 다중 테이블 간 관계 모델링, Flyway 기반 마이그레이션 자동화, CI/CD 배포 파이프라인 구축을 통해 실무 수준의 협업형 백엔드 개발을 경험했습니다.

Redis 대신 스케줄러 기반의 데이터 동기화 구조를 설계하여 운영 복잡도를 낮추었으며, 내부망 서비스 특성에 맞게 보안과 안정성을 중점적으로 고려했습니다. 현재는 코드 리팩토링과 테스트 자동화 단계를 진행 중입니다.
