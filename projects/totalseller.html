프로젝트 개요

👥 프로젝트 인원: 백엔드 2명 · 프론트엔드 1명

📅 개발 기간: 2025년 10월 13일 ~ 2025년 10월 30일 (리팩토링 진행 중)

🧑‍💻 담당 역할: 백엔드 설계, DB 모델링, Flyway 마이그레이션, 스케줄러 동기화 로직 구현, Swagger 문서 자동화, Docker 환경 배포

TotalSeller Backoffice는 내부 직원들이 클라이언트 계약과 오퍼링을 효율적으로 관리하기 위해 제작된 독립형 백오피스 시스템입니다.

프론트오피스는 별도의 개발팀이 담당하고 있으며, 백오피스는 완전히 분리된 MSA(Microservice Architecture) 구조로 구축되었습니다.

두 시스템은 실시간으로 연결되지 않고, 현재는 스케줄러(Scheduler) 기반으로 데이터를 동기화하고 있으며 향후에는 Webhook 기반 이벤트 동기화로 개선할 예정입니다.

📈 프로젝트 프로세스

  1. Admin이 각 팀을 생성하고 팀장 계정을 등록합니다.
  2. 직원은 회원가입을 통해 팀 가입을 신청합니다.
  3. 팀장은 요청을 승인 또는 반려할 수 있습니다.
  4. 승인된 직원은 제안서를 작성해 클라이언트에게 전달합니다.
  5. 클라이언트가 계약을 수락하면 직원은 오퍼링(Offering)을 생성합니다.
  6. 오퍼링에는 제안서, 계약서, 담당자, 카테고리 정보가 포함됩니다.
  7. 선택된 카테고리에 따라 프로세스 템플릿 데이터를 기반으로 프로세스가 자동 생성됩니다.
  8. 관리자는 팀별 진행률, 담당자 현황, 계약 상태를 한눈에 파악할 수 있습니다.

💡 프로젝트 회고

TotalSeller Backoffice는 단순한 관리 도구가 아닌, 조직과 계약의 흐름을 중심으로 한 내부 플랫폼입니다.

MSA 구조를 기반으로 프론트오피스와 완전히 분리된 독립 배포 환경을 구성했으며, 스케줄러 기반 데이터 동기화를 통해 시스템 간 일관성과 안정성을 확보했습니다.

Flyway를 도입하여 DB 마이그레이션의 이력 관리와 서버 간 일관성을 보장했고, Docker 기반의 컨테이너 환경을 통해 배포 자동화와 서비스 격리를 달성했습니다.

이 프로젝트를 통해 도메인 분리, 데이터 일관성, 비동기 구조 설계에 대한 실무 경험을 확립했으며, 내부 직원들의 업무 프로세스 효율성을 약 90% 향상시켰습니다.
