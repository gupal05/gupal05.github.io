프로젝트 개요

👥 프로젝트 인원: 백엔드 2명 · 프론트엔드 1명

📅 개발 기간: 2025년 10월 13일 ~ 2025년 10월 30일 (리팩토링 진행 중)

TotalSeller Backoffice는 내부 직원들이 클라이언트 계약 및 오퍼링을 효율적으로 관리하기 위해 개발된 내부 시스템입니다.

기존에는 엑셀과 카카오톡으로 계약 내용을 공유했기 때문에 담당자 파악, 계약 상태 확인, 팀 단위 진행 현황 파악이 매우 비효율적이었습니다.

이러한 문제를 해결하기 위해 팀 기반 승인 구조와 프로세스 자동화 시스템을 도입했습니다.

📈 프로젝트 프로세스

  1. Admin이 각 팀을 생성하고 팀장 계정을 등록합니다.
  2. 직원은 회원가입을 통해 팀 가입을 신청합니다.
  3. 팀장은 요청을 승인 또는 반려할 수 있습니다.
  4. 승인된 직원은 제안서를 작성해 클라이언트에게 전달합니다.
  5. 클라이언트가 계약을 수락하면 직원은 오퍼링(Offering)을 생성합니다.
  6. 오퍼링에는 제안서, 계약서, 담당자, 카테고리 정보가 포함됩니다.
  7. 선택된 카테고리에 따라 프로세스 템플릿 데이터를 기반으로 프로세스가 자동 생성됩니다.
  8. 관리자는 팀별 진행률, 담당자 현황, 계약 상태를 한눈에 파악할 수 있습니다.

💡 프로젝트 회고

TotalSeller Backoffice는 단순한 CRUD 백오피스가 아닌 조직형 협업 관리 플랫폼입니다.

팀 승인 흐름, 오퍼링 기반 계약 관리, 카테고리별 프로세스 자동화 등 실제 비즈니스 플로우를 완전히 디지털화했습니다.

이를 통해 JPA 성능 튜닝, Flyway 마이그레이션, Docker 배포 자동화 등 실무 중심의 아키텍처 설계 경험을 깊이 쌓을 수 있었습니다.
